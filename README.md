# Курс EASY TENDER в форме агента

Курс Алии по тендерам и госзакупкам Казахстана, который вы проходите вместе
со своим ИИ-агентом. Не видео и не конспект: агент ведёт вас по трассе из
17 шагов, вы делаете каждый шаг по-настоящему — на реальном портале
goszakup.gov.kz, — а агент помогает, считает и проверяет результат.

**Это пробная версия.** Наполнен один шаг — 7 «Найти пять тендеров».
Остальные шаги стоят заглушками и наполняются.

## Что нужно

1. **Claude Code** (или совместимый агент, умеющий читать файлы и запускать
   команды).
2. **Python 3.8+** — для скриптов работы с порталом. Windows: python.org,
   при установке отметить «Add to PATH». Если чего-то не хватит, скрипт сам
   скажет, что поставить.

ЭЦП и регистрация на портале для пробного шага **не нужны** — всё берётся
с публичной части.

## Как начать

Откройте эту папку в Claude Code и напишите агенту:

> Начнём курс

Агент прочитает ваш прогресс, скажет, где вы стоите, и поведёт по текущему
шагу. Один шаг за раз; шаг закрыт — когда выполнен его критерий зачёта.

## Как это устроено

```
kurs/         трасса: программа и 17 шагов, папка на шаг
metod/        правила ремесла — по ним агент считает и советует
engine/       скрипты сбора данных с портала
moya-rabota/  ваша рабочая папка: прогресс, ваши лоты и расчёты
```

Агент ничего не подаёт и не отправляет: любое действие на портале — подача
заявки, подписание — делаете вы сами, своим ключом. Агент читает, считает
и проверяет.
