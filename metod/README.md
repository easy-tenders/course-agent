# metod — правила ремесла

Карточки правил, по которым агент считает и советует. Правило пишется один
раз здесь; задания и теория шагов на него ссылаются.

**Происхождение:** карточки перенесены копией из базы EASY TENDER
(`tender-agent/method/`) 2026-08-29, для вертикального среза шага 7 — четыре:

- [[pravilo-sposoby-zakupki]] — ЗЦП, конкурс, аукцион; «из одного источника — не смотреть»
- [[pravilo-porogi-zcp]] — потолок ЗЦП и порог сертификата (числа 2025 года, МРП устарел)
- [[pravilo-ekonomika-tendera]] — затраты → выручка → прибыль; чего в расчёте не хватает
- [[pravilo-vhod-v-tendery]] — минимальный комплект для участия (шаги 1–6)

Остальные правила базы (демпинг, сертификаты, ЭСФ, коды, факторинг, агентская
сеть) подтянутся по мере наполнения шагов. Правишь правило в базе — перенеси
сюда руками; автоматики нет.

**Ссылки `[[...]]` внутри карточек** могут указывать на уроки и встречи,
которых в этом репозитории нет, — они живут в базе и на платформе курса.
