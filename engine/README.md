# engine — скрипты работы с порталом

Код собран для ученических шагов; запускает его агент, не человек руками.
Перенесён из базы EASY TENDER (`tender-agent/engine/`) 2026-08-29.

## Что нужно на машине

| Что | Зачем | Если нет |
|---|---|---|
| Python 3.8+ | всё | python.org, при установке отметить «Add to PATH» |

Сбор данных идёт стандартной библиотекой: внешних программ, ЭЦП и cookie не
нужно — всё берётся с публичной части портала. Скрипт, которому чего-то не
хватает, останавливается и пишет, что именно поставить.

## Скрипты

| Файл | Что делает | Шаг |
|---|---|---|
| `common.py` | общее: запросы к порталу с паузой, временные папки, чтение документов | библиотека |
| `scripts/collect_open.py "слово"` | все открытые лоты по ключевому слову с деталями | 7 |

Запуск — из папки `engine/`:

```
python scripts/collect_open.py "кондиционер"
```

Промежуточные данные скрипты кладут во временную папку системы (путь
печатается в конце), не в репозиторий. В `moya-rabota/` попадает только то,
что записано по заданию шага.

## Правила

- **Капчу не обходим.** Стоит защита — страницу открывает человек, агент читает.
- **Ничего не подаём и не отправляем.** Агент только читает.
- Между запросами к порталу — пауза (в `common.py`, отдельно не нужна).
- **В коде не должно быть путей чужой машины и чисел прогона.** Нашли — дефект.
