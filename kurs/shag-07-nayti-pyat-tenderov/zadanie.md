# Шаг 7. Найти пять тендеров

Первый шаг, где вы работаете с живым порталом. Задание из чек-листа Алии:
**найти пять тендеров, в которые вы могли бы зайти.**

## Что сделать

1. Выберите нишу — товар, который вам понятен (кондиционеры, канцтовары,
   мебель — что угодно, в чём вы сможете разобраться).
2. Скажите агенту ключевое слово — он соберёт открытые лоты с портала
   (`engine/scripts/collect_open.py`).
3. Отберите из списка **пять лотов** по правилам из [[teoriya]]:
   - способ закупки — **ЗЦП** (запрос ценовых предложений) — с него велит
     начинать Алия;
   - **«из одного источника» — не смотреть**: там поставщик уже приглашён
     (правка Алии по прогону 25.07.2026);
   - приём заявок ещё открыт — дедлайн в будущем;
   - товар вам понятен: вы сможете прочитать характеристику и найти такой
     у поставщика.
4. По каждому выбранному лоту напишите **два-три предложения: почему он** —
   своими словами.

## Критерий зачёта

Пять номеров закупок + объяснение выбора по каждому.

Проверяется двумя способами:

- **движком** — агент проверяет, что лоты существуют, открыты и подходят по
  способу закупки;
- **разговором** — агент смотрит ваши объяснения: не «первые пять из списка»,
  а осознанный выбор.

Порог по сумме лота у этого задания пока не задан — вопрос к Алии открыт.
Выбирайте сумму, которую вам не страшно потянуть.

## Куда записать

Агент кладёт результат в `moya-rabota/loty/shag-07-<ниша>.md`: таблица пяти
лотов (номер, заказчик, сумма, дедлайн) + ваши объяснения, — и отмечает шаг
в `moya-rabota/progress.md`.
